# به‌جا

وب‌سایت پیشنهاد کافه در تهران، با Next.js روی Node.js. برنامه برای اجرا روی سرور لینوکسی معمولی آماده شده و دیگر در زمان اجرا به Cloudflare Workers، D1 یا R2 وابسته نیست.

## اجرای محلی

- Node.js 22.13 یا جدیدتر
- `pnpm install`
- `pnpm dev`

برای ساخت نسخهٔ تولیدی از `pnpm build` و برای اجرای آن از `pnpm start` استفاده کنید.

## داده‌ها و ورود مدیر

- دیتابیس SQLite از ماژول `node:sqlite` خود Node استفاده می‌کند.
- مسیر دیتابیس با `DATABASE_PATH` و محل تصاویر آپلودشده با `UPLOAD_DIR` تنظیم می‌شود. هر دو را روی دیسک پایدار و خارج از پوشهٔ انتشار قرار دهید.
- برای ورود به `/admin`، متغیر `ADMIN_PASSWORD` را تنظیم کنید.
- امضای نشست مدیر از `ADMIN_SESSION_SECRET` استفاده می‌کند؛ این مقدار باید حداقل ۳۲ نویسهٔ تصادفی باشد.
- فایل نمونهٔ تنظیمات `.env.example` است. فایل‌های محیطی و پوشهٔ `data/` در Git نادیده گرفته می‌شوند.

## استقرار روی سرور ابری پارس‌پک

1. Ubuntu 24.04، Node.js 24 و pnpm 11.25 را نصب کنید.
2. مخزن را در `/opt/bejaaa` دریافت و با `pnpm install` وابستگی‌ها را نصب کنید.
3. `/var/lib/bejaaa` را برای دیتابیس و تصاویر بسازید و مجوز نوشتن را به کاربر سرویس بدهید.
4. متغیرهای `.env.example` را در `/etc/bejaaa/bejaaa.env` تنظیم کنید. رمز مدیر را قوی و `ADMIN_SESSION_SECRET` را با `openssl rand -hex 32` بسازید.
5. با `pnpm build` بسازید و برنامه را با `pnpm start` پشت Nginx اجرا کنید.
6. پس از بررسی سایت روی IP، رکوردهای DNS دامنه را به IP سرور تغییر دهید و گواهی HTTPS صادر کنید.

نمونهٔ فایل‌های Nginx و systemd در پوشهٔ `deploy/` قرار دارد. هر بار انتشار، کد را به‌روزرسانی و build کنید؛ دیتابیس و فایل‌های `/var/lib/bejaaa` را پاک نکنید.
